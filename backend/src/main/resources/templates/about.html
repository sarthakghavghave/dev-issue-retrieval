How It Works

1

GitHub → Neon Ingestion

The Spring Boot backend fetches issues from the GitHub API on a schedule and persists them to Neon PostgreSQL with metadata, labels, and comments.

2

NLP Preprocessing & Embedding

The FastAPI NLP service reads PENDING issues from Neon, cleans and filters text, generates MiniLM embeddings, and upserts vectors into the FAISS index.

3

Semantic Search

Your query is encoded and matched against the FAISS index. Top candidates are retrieved by cosine similarity in milliseconds.

4

Cross-Encoder Reranking

Jina API reranks the top candidates for precise relevance. Results are returned with labels, repository info, and GitHub links.

Technology Stack

Backend: Java 21, Spring Boot, Maven, Thymeleaf
Database: Neon PostgreSQL (cloud)
NLP Service: FastAPI, Python, Sentence Transformers
Models: Hugging Face - MiniLM and Jina reranker
Vector Index: FAISS (IndexFlatIP + ID mapping)
Deployment: Docker, Render
