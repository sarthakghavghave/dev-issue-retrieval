About Developer Issue Retrieval

Semantic search across GitHub issues — backed by Neon PostgreSQL, FAISS, and incremental ingestion

View source on GitHub →
🔍

Semantic Search

Describe your problem in natural language instead of guessing keywords. The system uses all-MiniLM-L6-v2 embeddings to find semantically similar GitHub issues across major open-source repositories.

☁️

Neon Cloud Database

All raw GitHub issue data is stored in a Neon PostgreSQL cloud database. Issues carry an index_status lifecycle (PENDING, INDEXED, FILTERED, FAILED) so only new or changed records enter the NLP pipeline.

⚡

FAISS Vector Retrieval

Preprocessed issues are encoded into dense vectors and stored in a FAISS index for sub-second similarity search over thousands of curated issue records.

🎯

TinyBERT Reranking

A cross-encoder/ms-marco-TinyBERT-L-2-v2 model reranks FAISS candidates so the most relevant issues surface first — optimized for low-memory cloud deployment.

🔄

Incremental Ingestion

A Spring Boot scheduler polls the GitHub API every 6 hours for updated issues across Spring Boot, Kafka, Kubernetes, Docker Compose, and PostgreSQL repos. New issues land in Neon as PENDING and are batch-processed into FAISS.

📊

Curated Dataset

~5,500+ indexed issues after preprocessing and deduplication, with ~8,000 raw records in Neon. Noise issues (docs, upgrades, duplicates) are filtered out with tracked filter_reason values.

How It Works

1

GitHub → Neon Ingestion

The Spring Boot backend fetches issues from the GitHub API on a schedule and persists them to Neon PostgreSQL with metadata, labels, and comments.

2

NLP Preprocessing & Embedding

The FastAPI NLP service reads PENDING issues from Neon, cleans and filters text, generates MiniLM embeddings, and upserts vectors into the FAISS index.

3

Semantic Search

Your query is encoded and matched against the FAISS index. Top candidates are retrieved by cosine similarity in milliseconds.

4

Cross-Encoder Reranking

TinyBERT reranks the top candidates for precise relevance. Results are returned with labels, repository info, and GitHub links.

Technology Stack

Backend: Java 21, Spring Boot, Maven, Thymeleaf
Database: Neon PostgreSQL (cloud)
NLP Service: FastAPI, Python, Sentence Transformers
Models: all-MiniLM-L6-v2 (embeddings), TinyBERT (reranking)
Vector Index: FAISS (IndexFlatIP + ID mapping)
Deployment: Docker, Render
