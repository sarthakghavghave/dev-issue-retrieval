System Architecture

Production architecture for semantic search over GitHub issues, combining offline indexing with an online retrieval pipeline and reranking service.

Offline Indexing Pipeline

GitHub Issues
Collect historical issue data from selected repositories and persist the raw issue text and metadata.
↓
PostgreSQL Storage
Store issue records and metadata in PostgreSQL for reliable persistence and query support.
↓
Preprocessing
Clean, normalize, and transform issue content into searchable text representations.
↓
Embedding Generation
Generate dense vector embeddings using a sentence transformer model for semantic similarity.
↓
FAISS Index Creation
Build and persist a FAISS vector index with associated issue metadata for fast retrieval.

Online Retrieval Pipeline

Spring Boot UI
Users submit natural language search queries through the web interface.
↓
FastAPI Retrieval Service
The frontend queries the retrieval API with the user request.
↓
Query Embedding
Convert the incoming query into a dense embedding that matches the indexed issue vectors.
↓
FAISS Candidate Retrieval
Retrieve the top candidate issue vectors from the FAISS index based on similarity.
↓
Cross-Encoder Reranking
Refine candidate ranking with a cross-encoder model to improve relevance ordering.

Architecture Summary

  • Offline indexing builds a persistent FAISS vector store from cleaned GitHub issue data and embeddings.
  • The online pipeline transforms user queries to vectors, retrieves candidates from FAISS, and reranks them.
  • Results include issue metadata, labels, repository information and source links for user exploration.
  • This separation of offline indexing and online retrieval enables fast query response times.
